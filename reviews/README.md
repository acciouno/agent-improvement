# Outer-Loop Reviews

The outer loop is what turns task experience into system improvement. It runs
whenever you ask for a review (suggested cadence: weekly). Each review follows
`review-template.md` and appends a row to `review-log.md`.

The paper's warning that motivates this directory: persistence is not
progress. A system that logs everything but never examines the log is B0 with
a filing cabinet. The review is the mechanism that closes the loop.

Every review ends by stating three things: what was done, what was verified
and how, and what remains. Silence after a complex step is a failure mode —
if the sweep didn't finish, say so and say what's left.
